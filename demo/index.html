spotlight-tour · demo

Onboarding tours with a camera effect

The page pulls back, and each element you want to show flies out to the front of the screen. Both demos below are the same app. The only difference is the library.

Without spotlight-tour

The app as it is. New users find their way around on their own.

With spotlight-tour

The same app with the library installed. The tour starts on its own, and the last steps ask you to use the real page: switch the billing, type your email, sign up. Nothing is sent.

Install it

Not on npm yet. npm builds it from GitHub on install.

npm install github:cesarureno/spotlight-tour-js
import SpotlightTour from 'spotlight-tour';

const tour = new SpotlightTour({
  steps: [
    { target: '#main-nav', title: 'Main navigation', text: 'Every section is here.' },
    { target: '#cta-btn',  title: 'Get started',     text: 'Create your account.', cloneScale: 3 },
  ],
});

tour.start();
